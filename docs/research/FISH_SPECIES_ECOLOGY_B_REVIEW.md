確認日: 2026-07-26

Issue #309 / PR #314 の正本レビュー。底物・砂地系7エントリを v1.3.0 の自己完結型調査記録として整理する。

## Source と制約

- 分類・名称は各JSONに記録したGBIFを使用する。`kisu` は日本の公的研究機関による直接照合を補うため、JAMSTEC BISMaLの「シロギス / *Sillago japonica*」対応も使用する。
- 一般水深・底質/生息環境・水域は、編集責任が明確な二次sourceであるFishBase species summaryを一般生態の説明に限って使用する。各claimとsourceの `supports` は双方向に対応させた。
- `maanago` のFishBaseにある320〜830 mは、日本沿岸の砂泥底という同ページの生活域説明と分け、限定的な深所記録としてcheckedに留めた。日本沿岸での代表的な一般水深を安全に確定できないため `depthRange` は `unknown / hold` とし、岸から狙える水深や地域相性へ変換しない。
- `umazurahagi` のFishBaseにある10〜28℃は、種の一般生息環境（climate zone）の水温としてのみ採用する。釣れやすい適水温ではなく、`regionalCatchability` またはSCORE v2の水温閾値へ転用しない。
- `magochi` は表示名に対する現行の単一taxon確定ができない。特定候補種の値を表示カテゴリへ暗黙継承せず、全一般生態をholdする。
- 根拠を取得できなかった季節性、一般適水温、昼夜行動、遊漁の釣法はholdする。産卵期・産卵水温・漁期・水揚げ時期を釣期や適水温へ読み替えない。

## 一般生態を地域の釣れやすさ / SCOREへ転用しない理由

FishBaseの水深は種の一般的な生息水深であり、岸から届く水深ではない。底質・水域も、糸島〜唐津湾〜伊万里湾〜平戸の特定地点における出現や陸っぱりでの釣れやすさを直接示さない。対象地域・釣法・時期・観測条件を結び付ける直接根拠がないため、全7エントリの `regionalCatchability` は `unknown / hold`、`scoreV2Status` は `unsupported` のままとする。二次sourceの数値をSCORE閾値へ直接採用しない。

## 再確認条件

地域別属性は、対象地域の陸っぱり釣果を魚種・場所・時期・条件とともに直接示す、公的機関または利用許諾を確認した資料が得られた場合に再評価する。`magochi` は日本産マゴチ類の分類とアプリmasterの指示対象を直接対応できる資料取得時に、`kisu` はmasterがキス科グループへ変更される場合にidentityを再評価する。
