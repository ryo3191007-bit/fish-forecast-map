# Issue #363 唐津東港 実釣候補岸PoC 調査記録

確認日: 2026-07-28  
対象地点: `karatsu-east-port` / 唐津東港  
現在の代表座標: `33.469823, 129.963189`

## 結論

唐津東港について、岸の位置形状を `LineString` で持ち、物理的な岸の存在・一般立入・釣り利用を分離するデータモデルは成立する。

一方、2026-07-28時点の公式・公的資料だけでは、**釣り利用可能で、かつ0〜150m近岸距離計算の基準に使える精度を持つ岸区間はまだ確定できない**。

したがってPoCでは、東港岸壁の公的な概位と延長から作った研究用概略線を保存するが、`fishingUseStatus: unknown`、`distanceReferenceStatus: not_eligible` とする。

## 確認した事実

### 東港岸壁

国土交通省 九州地方整備局 唐津港湾事務所の2026年版唐津港パンフレットでは、東港地区に次の施設がある。

- 東港フェリー岸壁: 水深 -4.5m、延長115m、1バース
- 東港岸壁: 水深 -9.0m、延長230m、1バース

海上保安庁の九州沿岸水路誌追補では、東港岸壁の概位を `33°28.2′N, 129°57.9′E`、延長230m、水深約9mとしている。

物理的な岸壁の存在は確認できるが、概位情報であり精密岸線ではない。

### 県管理の東港沿岸施設

佐賀県が2024年6月5日に公示した県管理港湾施設の概要では、唐津港東港地区に少なくとも次の沿岸施設が掲載されている。

- `東港護岸`: 延長129m
- `東港臨港道路護岸`: 延長531m
- `東港フェリー取付護岸`: 延長43m
- `東港緑地護岸`: 延長140m
- `東港大島1号護岸`: 延長56.9m
- `東港大島2号護岸`: 延長163m
- `東港大島3号護岸`: 延長34m
- `東港2号物揚場`: 延長127m、水深 -1m
- `東港3号物揚場`: 延長225m、水深 -4m
- `東港東防波堤`: 延長240m
- `東港西1号防波堤`: 延長393m
- `東港西2号防波堤`: 延長190m
- `東港西3号防波堤`: 延長50m
- `東港船溜防波堤`: 延長250m
- `東港緑地`: 面積26,000㎡

特に `東港緑地護岸` は、一般向け交流空間として確認できる東港緑地・水際プロムナードとの関係を優先調査する候補とする。ただし、この公示は施設名称・延長・面積を示すもので、各施設の端点座標や釣り利用可否までは示していない。

### 一般立入

国土交通省のみなとオアシス案内では、唐津東港地区の構成施設として水際プロムナード、緑地、東港耐震強化岸壁が示され、水際プロムナード・緑地はイベント、休憩、トイレ等に利用される地域交流空間として案内されている。

佐賀県の令和6年度公共事業再評価資料でも、東港地区を「人の集う空間」とするため遊歩道・広場・植栽・休憩所等を整備し、日常的に人々が集い交流する緑地を目指していることが確認できる。令和6年6月には芝生広場が完成し、令和6年度末時点の事業進捗は83.5%とされている。

一方、唐津市の2026年7月15日クルーズ船寄港案内では、東港地区岸壁の制限区域フェンス内へ入場するには立入手続きが必要とされている。

このため、「東港地区に一般向け水際空間がある」ことと、「東港岸壁そのものへ常時自由に立ち入れる」ことを分離する。後者は `unknown` とする。

### 港湾管理上の利用ルール

佐賀県港湾管理条例では、国際港湾施設の制限区域への正当な理由のない立入りを禁止し、港湾施設の目的・能力に照らして適切でない使用や港湾機能を妨げる行為も禁止している。また、管理上必要な場合は個別施設の使用を禁止・制限できる。

条例自体に「唐津東港の釣りを一律禁止する」とする規定は確認できないが、これを釣り許可の根拠にも使わない。施設単位の制限・現地掲示・管理者運用を確認する必要がある。

### 釣り利用

今回確認した公式・公的資料には、東港岸壁、東港緑地護岸または水際プロムナードでの釣りを明示的に許可する記載を確認できなかった。

したがって釣り利用可否は `unknown` とする。

## SeaShiru再PoCへの条件

SeaShiruの底質・海底障害物・沈船・ESIを0〜150mの陸っぱり情報として評価するのは、次を満たす岸区間を確認した後とする。

1. 位置形状が距離計算に使える精度で確認できる。
2. 一般立入可否が確認できる。
3. 釣り利用可否が確認できる、または少なくともユーザーが実際に使用する釣り位置として本人実地確認できる。

旧座標 `33.459, 129.993` を中心に実施したSeaShiru PoCは、現在の唐津東港の採否判断には使用しない。

## 次の調査候補

優先順は次のとおり。

1. `東港緑地護岸` 140mと水際プロムナードの位置関係を、公的図面または管理者資料で特定する。
2. 東港緑地護岸・水際プロムナードについて、一般立入と釣り利用の現行ルールを佐賀県唐津土木事務所 港湾課 / 唐津市みなと振興課の案内で確認する。
3. 公的資料で釣り利用可否まで確認できなければ、本人現地確認で釣り位置・フェンス・禁止表示・足場を記録する。
4. 十分な位置精度と利用根拠がそろった区間だけを `distanceReferenceStatus: eligible` とする。

推測で釣り可能区間を作成しない。
