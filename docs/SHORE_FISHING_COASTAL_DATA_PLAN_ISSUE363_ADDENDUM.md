# Issue #363 追補: 唐津東港実釣候補岸PoCとSeaShiru再検証

確認日: 2026-07-28  
対象Issue: #363  
関連正本: `docs/SHORE_FISHING_COASTAL_DATA_PLAN.md`

## 1. この追補の優先関係

Issue #361 / PR #362で作成した沿岸データ取得方針のうち、SeaShiru PoCの採否判断と「次の一手」は本追補で訂正する。

理由は、最初のSeaShiru PoCが唐津東港の旧座標 `33.459, 129.993` を中心に実施されていた一方、Issue #294 / PR #295で現在の `main` の唐津東港代表座標は `33.469823, 129.963189` へ補正済みだったためである。

旧座標と現在座標は約3km離れており、旧座標を中心とした半径1km検索結果を現在の唐津東港の近岸データ密度として評価できない。

したがって、旧PoCを根拠にした次の判断は撤回する。

- SeaShiru底質は陸っぱり用途に使えない。
- SeaShiru海底障害物は陸っぱり用途に使えない。
- SeaShiru沈船は陸っぱり用途に使えない。
- ESIは唐津東港の近岸距離判定に使えない。

これらはすべて **採否未判定** に戻す。

## 2. Issue #363 PoCの目的

先に「実釣候補岸」を独立データとして表現し、その岸が0〜150m近岸調査の距離基準として利用できるか判定する。

必ず次を分離する。

1. 岸・岸壁・護岸等が物理的に存在するか。
2. 一般に立ち入れるか。
3. 釣り利用可能か。

一般利用できる水際空間が存在しても、釣り可能とは推定しない。

## 3. 唐津東港の現時点の確認結果

### 物理的な岸壁

国土交通省 九州地方整備局 唐津港湾事務所の2026年版唐津港パンフレットでは、東港地区に次の港湾施設を掲載している。

- 東港フェリー岸壁: 水深 -4.5m、延長115m、1バース。
- 東港岸壁: 水深 -9.0m、延長230m、1バース。

海上保安庁の九州沿岸水路誌追補では、東港岸壁の概位を `33°28.2′N, 129°57.9′E`、延長230mとしている。

この公的情報から、東港岸壁が物理的に存在することは確認できる。ただし、水路誌の座標は概位であり、岸端の精密測量線ではない。

### 一般立入

唐津市の2026年7月15日クルーズ船寄港案内では、唐津港東港地区岸壁の「制限区域のフェンス内」への入場には立入手続きが必要とされている。

これは東港岸壁に利用制限区域が存在する運用例の根拠にはなるが、岸壁全体の恒常的な一般立入可否を確定する根拠にはしない。現時点では `unknown` とする。

一方、国土交通省のみなとオアシス案内では、東港地区に水際プロムナード・緑地があり、イベント・休憩・トイレ等のサービス空間として案内されている。全国ロケーションデータベースでも東大島町1の唐津東港について海辺のベンチ、レンガ敷き通路、街路灯がある水際空間を確認できる。

ただし、この公開情報だけでは水際プロムナードの正確なLineStringを確定できないため、0〜150m距離計算の基準にはまだ採用しない。

### 釣り利用

今回確認した公式・公的資料から、東港岸壁または水際プロムナードでの釣りを明示的に許可する根拠は確認できていない。

したがって `fishingUseStatus` は `unknown` とする。

## 4. PoCデータの位置づけ

`data/research/shore-fishing-segments/karatsu-east-port.poc.json` に、東港岸壁の公的な概位・延長を基にしたPoC用LineStringを保存する。

このLineStringは、

- schemaがLineStringを保持できること、
- 現在の唐津東港代表座標周辺を対象にしていること、
- physical / publicAccess / fishingUseを分離できること、

を確認するための**研究用概略線**である。

`distanceReferenceStatus: not_eligible` とし、SeaShiruや水深の150m距離計算には使用しない。

## 5. 次の一手

1. 唐津東港の水際プロムナード等について、正確な位置形状を公的地図・管理者資料・現地確認で詰める。
2. 一般立入可否と釣り利用可否を別々に確認する。
3. 十分な位置精度と利用根拠を持つ区間だけ `distanceReferenceStatus: eligible` とする。
4. eligibleな岸が得られたら、その岸から0〜150mでSeaShiruの底質・海底障害物・沈船・ESIを再PoCする。
5. SeaShiruの採否をその結果で決める。
6. その後、高精細水深DEM等のcoverage監査へ進む。

## 6. 変更しないもの

- 既存spotId
- 現在の代表座標
- SCORE v2
- Supabase既存データ
- 既存釣果
- 安全・規制情報

不明値は不明のまま保持する。
